# OrbitalGameEnv

本项目是一个基于强化学习的卫星轨道追逃博弈仿真环境。它旨在模拟多智能体（追击方和逃逸方）在轨道空间中的对抗行为。

## 核心模块与关系

本项目的核心逻辑由几个关键的Python文件组成，它们共同定义了仿真环境、智能体模型和训练流程。下面将详细介绍这些文件及其相互关系。

### 文件概览

-   `env/mpe_env.py`: 定义了一个 **完全可观测** 的多智能体追逃环境 (`MPEEnv`)。
-   `env/mpe_pomdp_env.py`: 定义了一个 **部分可观测** 的多智能体追逃环境 (`MPE_POMDP_Env`)。
-   `env/lstm.py`: 实现了一个基于LSTM的轨迹预测模型 (`TrajectoryPredictor`)，用于处理部分可观测性问题。
-   `demos/pe_env/train.py`: 针对 **完全可观测** 环境的训练脚本。
-   `demos/pe_env/train_pomdp.py`: 针对 **部分可观测** 环境的训练脚本。

### 详细介绍与关系

#### 1. 仿真环境

##### `env/mpe_env.py` (完全可观测环境 - MDP)

这是项目的基础环境，实现了一个完全可观测的马尔可夫决策过程（MDP）。在此环境中：
-   **完全信息**：所有追击方在任何时刻都能精确地知道逃逸方和其他追击方的状态（位置、速度）。
-   **观测空间**：追击方的观测直接包含所有智能体的真实状态。
-   **奖励机制**：设计了复杂的奖励函数，包括距离、队形、燃料消耗和过程优势等，以引导追击方学习协作。
-   **课程学习**：支持通过动态调整任务难度（如初始燃料、捕获距离）来加速模型收敛。

##### `env/mpe_pomdp_env.py` (部分可观测环境 - POMDP)

该文件继承自 `MPEEnv`，构建了一个更真实、更具挑战性的部分可观测环境（POMDP）。
-   **部分信息**：模拟现实场景，追击方无法连续获得逃逸方的精确位置。观测是 **间歇性** 的。
-   **应对挑战**：为了弥补信息的缺失，该环境引入了轨迹预测机制。它不直接向追击方提供逃逸方的真实位置，而是提供一个基于历史数据预测的未来轨迹。
-   **与 `lstm.py` 的关系**：此环境依赖于 `lstm.py` 中定义的 `TrajectoryPredictor` 模型来生成对逃逸方轨迹的预测。

#### 2. AI 模型

##### `env/lstm.py` (轨迹预测模型)

该文件定义了 `TrajectoryPredictor` 类，这是一个基于LSTM的深度学习模型。
-   **核心功能**：接收逃逸方过去一段时间的状态序列（历史轨迹），并预测其未来一段时间的绝对位置。
-   **目的**：在 `mpe_pomdp_env.py` 中，当真实的观测数据不可用时，这个模型的预测结果将作为追击方决策的依据，从而缓解部分可观测性带来的困难。

#### 3. 训练流程

##### `demos/pe_env/train.py` (MDP环境训练脚本)

此脚本用于训练在 **完全可观测** 环境 (`mpe_env.py`) 中运行的智能体。
-   **算法**：采用多智能体近端策略优化（MAPPO），其中包含一个中心化的Critic来评估全局状态，指导各个Actor（追击方）的学习。
-   **工作流**：`train.py` 实例化 `MPEEnv` 环境和 `ActorCritic` 网络，然后在一个标准的强化学习循环中进行数据采集和模型更新。

##### `demos/pe_env/train_pomdp.py` (POMDP环境训练脚本)

此脚本用于训练在 **部分可观测** 环境 (`mpe_pomdp_env.py`) 中运行的智能体。
-   **混合训练**：这是一个更复杂的训练流程，它结合了 **强化学习 (RL)** 和 **监督学习 (SL)**。
    -   **RL部分**：与 `train.py` 类似，使用PPO算法更新追击方的决策网络（Actor-Critic）。
    -   **SL部分**：在仿真过程中，环境会记录逃逸方的真实历史轨迹和未来轨迹。这些数据被用来作为监督学习的样本，训练 `lstm.py` 中的 `TrajectoryPredictor` 模型，使其预测越来越准。
-   **工作流**：
    1.  `train_pomdp.py` 实例化 `MPE_POMDP_Env` 环境，并创建一个包含决策网络和 `TrajectoryPredictor` 的组合模型。
    2.  在与环境交互时，`MPE_POMDP_Env` 使用LSTM模型生成预测，并将其作为观测的一部分提供给追击方。同时，环境也为监督学习准备好输入（历史轨迹）和标签（未来真实轨迹）。
    3.  在模型更新阶段，脚本使用两个独立的优化器：一个用PPO损失更新决策网络，另一个用均方误差（MSE）损失更新LSTM预测模型。
